# Hearbeat-animation
A simple animation that simulates a heartbeat effect.
This project  demonstrates how to use CSS keyframes and transform property to create smooth, eye-catching animations

Live Demo
[view project Here](https://heartanima.netlify.app)

Features
-Smooth heartbeat animation using CSS Keyframes
-Scalable and reusable design

Tech Stack
-HTML
-CSS(animations, Transform)
